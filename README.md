# HelperValley

An unofficial Stardew Valley companion that reads **your local save files** in the browser
to track progress toward 100% Perfection, the Community Center, the Museum, relationships,
your farm and more. Nothing is uploaded: saves are parsed entirely on your machine.

Live site: https://mauricioaires30.github.io/HelperValley/

## Development

```bash
npm install
npm run dev
```

- `npm test` runs the unit tests.
- `npm run extract` regenerates `public/data` and `public/sprites` from a local game install
  (see `tools/extract/README.md`).
