# HelperValley

**English** · [Português](README.pt-BR.md)

An unofficial Stardew Valley companion that reads **your local save files** in the browser
to track progress toward 100% Perfection, the Community Center, the Museum, relationships,
your farm and more. Nothing is uploaded: saves are parsed entirely on your machine.

- **Live site:** https://mauricioaires30.github.io/HelperValley/
- **Author:** Maurício Aires · [Portfolio](https://mauricioaires30.github.io)

## How to use

1. Open the site in Chrome or Edge.
2. Click **Open Saves folder** and pick `%AppData%\StardewValley\Saves`.
3. Play as usual: every time the game saves (when you sleep), the page updates on its own.

Multiplayer saves are supported: choose which player to view in the header.
Other browsers can select the folder too, but need to select it again to refresh.
